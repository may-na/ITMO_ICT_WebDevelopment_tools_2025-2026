# Практика 1 — основы FastAPI (in-memory)

Учебное приложение к **Практике 1**: знакомство с FastAPI без подключения к
настоящей базе данных. Данные хранятся во временной структуре в памяти (список
объектов), что позволяет сосредоточиться на самом фреймворке.

## Что показано

- модели на Pydantic (`BaseModel`) и строгая типизация;
- перечисления `Enum` (`Currency`, `OperationType`);
- **вложенный объект** (`owner`) и **список вложенных объектов** (`operations`)
  в основной сущности `Wallet`;
- CRUD основной сущности (кошельки) и API для вложенной сущности (операции);
- автодокументация Swagger UI.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install fastapi "uvicorn[standard]"
uvicorn main:app --reload
```

Документация: <http://127.0.0.1:8000/docs>

## Эндпоинты

| Метод  | Путь                              | Назначение                          |
|--------|-----------------------------------|-------------------------------------|
| GET    | `/wallets`                        | список кошельков                    |
| GET    | `/wallets/{id}`                   | кошелёк с владельцем и операциями   |
| POST   | `/wallets`                        | создать кошелёк                     |
| PUT    | `/wallets/{id}`                   | обновить кошелёк                    |
| DELETE | `/wallets/{id}`                   | удалить кошелёк                     |
| GET    | `/wallets/{id}/operations`        | операции кошелька (вложенная сущн.) |
| POST   | `/wallets/{id}/operations`        | добавить операцию, пересчитать баланс |
